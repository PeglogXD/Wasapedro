# WasaPedro

WhatsApp para Chromebooks hecho por Pedro Paz.

Al abrir el archivo entras directo a WasaPedro. Pones tu nombre, tu correo e ingresas al sistema; en agregar ID pones el nombre de tu amigo y podrán hablar.

Funciones: mensajes, GIFs, stickers, emojis, audios y otros archivos, videollamada y compartir pantalla.
